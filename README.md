# Контрольная работа №2 (PowerShop)

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание
Учебный интернет-магазин экипировки для пауэрлифтинга, разработанный с использованием фреймворка Bootstrap 5.

## Используемые технологии
- HTML5
- Bootstrap 5 (локальное подключение)
- CSS (custom.css)
- Git / GitHub

## Структура проекта
- `index.html` – главная страница
- `catalog.html` – каталог товаров
- `product.html` – карточка товара
- `order.html` – форма заявки
- `css/custom.css` – кастомные стили
- `vendor/bootstrap/` – локальные файлы Bootstrap
- `images/` – изображения товаров и фонов

## Практическая работа 9: Bootstrap-сетка
Выполнена главная страница на Bootstrap-сетке. Использованы классы `container`, `row`, `col-*`, адаптивные колонки (`col-12`, `col-md-*`, `col-lg-*`), отступы (`g-*`, `my-*`, `p-*`). Созданы шапка, навигация, hero-блок, блок преимуществ, сетка популярных товаров и подвал.

## Практическая работа 10: Bootstrap-компоненты
Добавлены страницы `catalog.html`, `product.html`, `order.html`. Использованы следующие компоненты:
- `navbar` — единая навигация на всех страницах;
- `card` — карточки товаров в каталоге;
- `modal` — модальное окно быстрой заявки;
- `accordion` — блок «Частые вопросы» на странице товара;
- `badge` — метки товаров («Новинка», «Хит», «Скидка»);
- `alert` — информационные сообщения;
- `btn` — кнопки действий;
- `form-control`, `form-select`, `input-group`, `form-check` — элементы формы заявки;
- `breadcrumb` — хлебные крошки на странице товара.

## Самостоятельные доработки
- **Собственная тематика**: проект переработан под магазин экипировки для пауэрлифтинга (PowerShop).
- **Локальное подключение Bootstrap**: фреймворк подключен без CDN из папки `vendor/bootstrap/`.
- **Карусель (Carousel)**: добавлена на главную страницу с реальными фото товаров.
- **Всплывающие уведомления (Toast)**: добавлены на страницу заявки для информирования об успешной отправке.
- **Работа с изображениями**: добавлены реальные фото товаров в карточки и карусель.
- **Визуальная целостность**: кастомный фон, темная шапка с логотипом SBD, акцентный красный цвет (`bg-danger`) для кнопок и элементов.
