# Контрольная работа №2 (Bootstrap Shop)

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание
Учебный интернет-магазин, разработанный с использованием фреймворка Bootstrap 5.

## Используемые технологии
- HTML
- Bootstrap 5 (CDN)
- CSS (custom.css)
- Git / GitHub

## Структура проекта
- `index.html` – главная страница
- `catalog.html` – каталог
- `product.html` – карточка товара
- `order.html` – форма заявки
- `css/custom.css` – кастомные стили
